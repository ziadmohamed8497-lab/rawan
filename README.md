# Our Story — نسخة HTML + CSS + JavaScript

موقع ثابت من غير Node ولا npm ولا بناء. مجلد واحد.

## التشغيل
- جرّبيه محليًا: افتحي `index.html` في المتصفح، أو الأفضل من سيرفر بسيط داخل المجلد:
  `python3 -m http.server 8000` ثم افتحي http://localhost:8000
- النشر: ارفعي المجلد كله على أي استضافة ملفات ثابتة (Netlify / GitHub Pages / Cloudflare Pages / استضافة عادية).

## الملفات
```
index.html        الصفحة (الشاشات الثلاث + الأقسام)
css/style.css     كل التصميم
js/config.js      كل النصوص والرسائل والتواريخ والصور (عدّلي هنا)
js/utils.js       قراءة التاريخ، SHA-256، العد التنازلي
js/app.js         التدفق والتفاعلات
tools.html        أداة لتغيير تاريخ الدخول (احذفيها قبل النشر)
images/photos/    memory-01.webp ... surprise-01.webp ... hero.webp
audio/            our-song.mp3 (مرخّص)
```

## الصور والموسيقى
حطي الصور في `images/photos/` بالأسماء المكتوبة في `config.js` (أو أضيفي أسماء جديدة هناك). لحد ما الملف يتحط بيظهر Placeholder واضح باسمه. الموسيقى ملف `audio/our-song.mp3`، ومبتشتغلش إلا لما تضغطي Play.

## تنبيه مهم عن الحماية
الموقع من غير سيرفر، فالتحقق من التاريخ بيحصل **في المتصفح**:
- التاريخ نفسه مش مكتوب في الكود، المكتوب بصمة SHA-256 له، لكن **أي حد عنده خبرة يقدر يتخطى الشاشة السرية** أو يقرا `config.js` (فيه نصوص الرسائل) والصور مباشرة من الرابط.
- ده مناسب كلعبة رومانسية وهدية، **مش** لحماية محتوى حساس. لو الصور والرسائل خاصة فعلًا، استخدمي نسخة Next.js (التحقق على السيرفر)، أو خلّي الرابط سري ومتشاركش الصور الحساسة.
- محاولات التخمين محدودة (6 كل 10 دقايق) لكن ده في المتصفح، فمجرد تقليل.
